# modules/gui

- Храни здесь окна, диалоги, виджеты, модели отображения и GUI-worker.
- GUI не должен содержать бизнес-логику, чтение Excel/PDF, SQL или почтовые
  сценарии.
- Долгие операции запускай через worker и вызывай `modules/services`.
- Пользовательские ошибки показывай понятно, а диагностический контекст логируй.
- Интерфейс должен быть написан на PySide6.
- Импорты PySide6 размещай в начале модуля.
- Не выполняй импорты PySide6 внутри функций и методов.
