# modules/pdf

- Вся логика работы с PDF живёт здесь: чтение, генерация, заполнение форм,
  проверка страниц и визуальная верификация.
- Не изменяй исходный PDF напрямую; результат сохраняй в отдельный файл.
- `readers` извлекает данные, `writers` генерирует или заполняет PDF,
  `validators` проверяет структуру и содержимое.
- Общий порядок обработки PDF собирай в `modules/services`.
