# modules/models

- Используй пакет для моделей переноса данных, если они не являются чистым
  доменом и не относятся к HTTP-схемам.
- Новые модели оформляй через `dataclass`, если нет причины использовать другую
  структуру.
- Не добавляй сюда чтение файлов, GUI и работу с БД.
- Модели через `dataclass` используй также для того, чтобы передавать данные между модулями. Использую их как контейнер данных.
