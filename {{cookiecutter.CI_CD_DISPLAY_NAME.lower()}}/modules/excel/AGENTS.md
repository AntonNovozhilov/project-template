# modules/excel

- Вся логика работы с книгами Excel живёт здесь: чтение, запись, проверка,
  стили, шаблоны и OOXML-детали.
- Не изменяй исходные книги. Для записи используй копию шаблона или отдельный
  выходной файл.
- `readers` только извлекает данные, `writers` только сохраняет результат,
  `validators` проверяет структуру, `ooxml` работает с ZIP/XML-уровнем XLSX.
- Общий порядок обработки Excel собирай в `modules/services`, не в этом пакете.
