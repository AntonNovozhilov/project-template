# modules/excel/readers

- Один reader должен читать один тип входной книги или один устойчивый контракт
  листа.
- Определяй данные по заголовкам и явным правилам, а не по имени файла, если
  это не утверждённый бизнес-контракт.
- Reader возвращает dataclass или простую структуру, но не запускает пайплайн.
