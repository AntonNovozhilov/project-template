# modules/excel/writers

- Writer сохраняет результат в новый файл или в копию утверждённого шаблона.
- Сохраняй формулы, стили, фиксированные строки и структуру шаблона, если это
  часть контракта.
- Не пересчитывай Excel-формулы через openpyxl; для фактической проверки
  результата нужен Excel или LibreOffice.
- Если от пользователя требуется пересчёт формул после сохранения книги. То для Linox System используй LibreOffice В скрытом режиме. А для Windows System используй Excel COM.
- Пути к папкам и файлам необходимо валидировать и делать проверку. Существует ли папка или файл? Можно ли её прочитать? Какой формат у файла?
- При попытке создания новой книги необходимо делать это через временную директорию. Использу для этого TemporaryDirectory.
После создания файлов во временной директории попытайся их прочитать. Если чтение проходит успешно, то атомарно замени по нужному пути.
