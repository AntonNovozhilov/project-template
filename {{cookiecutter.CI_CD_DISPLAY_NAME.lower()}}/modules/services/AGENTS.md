# modules/services

- Это обязательный пакет сценариев приложения.
- Сервис собирает пайплайн в классе с поятным именем. Главная функция в нем run() - собирает всю логику.
- Не размещай здесь низкоуровневую логику Excel/PDF/GUI/SQL/SMTP. Ее ты вызываешь из соотвевующего пакета.
- Один самостоятельный use-case оформляй отдельным классом.
- Сервисный интерфейс должен быть узким: входные параметры, результат и понятные
  исключения.
