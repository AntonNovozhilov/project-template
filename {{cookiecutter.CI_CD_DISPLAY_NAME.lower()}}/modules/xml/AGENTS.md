# modules/xml

- Храни здесь общую работу с XML, которая не относится напрямую к OOXML Excel.
- Не обрабатывай XML регулярными выражениями.
- Не изменяй структуру XML без запроса пользователя.
- Не переименовывай элементы, атрибуты или namespace URI без явного требования.
- по умолчанию используй xml.etree.ElementTree
